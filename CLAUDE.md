# SaglamSpot — Claude notları

Flutter (Android/iOS/web) mobilya vitrini. UI, tasarım, animasyon veya
performans işi yapmadan önce proje skill'lerini oku:

- `.claude/skills/saglamspot-ui/SKILL.md` — **önce bu**: dokunulmaz
  ekranlar (Keşfet dikey kategori rayı, ürün kartı), token'lar, performans.
- `.claude/skills/frontend-design/SKILL.md` — görsel yön, tipografi,
  responsive genişlik (Flutter uyarlaması).
- `.claude/skills/mobile-design/` — mobil tasarım/dokunma/performans
  referansları.
- `.claude/skills/flutter-motion/SKILL.md` — animasyon kuralları.

Kontrol: `flutter analyze` (yeni error/warning olmamalı).
